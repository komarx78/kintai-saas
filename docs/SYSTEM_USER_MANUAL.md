# 第1章：システム全貌と基本アーキテクチャ

## 1.1 システムの目的・概要
本システムは、従来ばらばらに管理されていた「入退社手続き・雇用契約締結」「日々の勤怠打刻・残業管理」「店舗・現場のシフト作成」「月次給与計算・Web給与明細」「法定三帳簿・行政公的届出書」を単一のクラウドプラットフォーム上に統合した、中小〜中堅企業向けのオールインワン労務管理SaaSです。

紙やExcelでの二重入力、行政書面の手書き転記、法改正に伴う料率計算ミスをゼロにし、従業員・管理者・社会保険労務士・経営者すべての業務負荷を90%以上削減します。

## 1.2 大元真実マスタ（SSOT: Single Source of Truth）アーキテクチャ
本システムの最大の特徴は、**「入退社労務書類管理システム」を唯一の真実（SSOT）**とするデータ連動アーキテクチャです。

```
[入社手続き / 従業員台帳 (SSOT)]
  │
  ├─ 氏名・住所・生年月日・基礎年金番号・マイナンバー
  ├─ 雇用区分・所属部署・役職・就業時間パターン
  ├─ 基本給・各種手当（役職・住宅・家族・資格）・通勤手当
  ├─ 健保・厚年標準報酬月額・雇用保険・住民税月別額
  │
  ├──────▶ [勤怠管理・有給管理]（就業時間・休日カレンダー・有給付与日を自動参照）
  ├──────▶ [シフト管理]（所属・可能職種・出勤可能時間を自動参照）
  ├──────▶ [給与計算エンジン]（勤怠実績 × 基本給・手当・料率で自動算出）
  ├──────▶ [Web給与明細]（計算結果を従業員スマホへ即座に配信）
  ├──────▶ [公的帳票・行政届出]（労働者名簿・賃金台帳・資格取得届へ自動流し込み）
  └──────▶ [産休・育休手続き]（予定日連動で期間・住民税立替を自動計算）
```

これにより、下流の機能で従業員データを再入力する必要は一切ありません。大元マスタを一度更新するだけで、全サブシステムへ瞬時にリアルタイム反映されます。

## 1.3 利用者権限（3大ロール体系）
システム内の機能は、情報セキュリティと個人情報保護法に基づき、厳格に3つのロールに分離されています。

| ロール | 権限範囲 | 利用可能画面 |
| :--- | :--- | :--- |
| **最高統括管理者 (Super Admin)** | SaaSプラットフォーム全体の運営権限 | 全社テナント管理、プラン変更、試用期間管理、システム利用料マスタ設定 |
| **企業・労務管理者 (Admin)** | 自社テナント内の全機能・全従業員データの管理権限 | 労務管理、従業員台帳、書類審査、勤怠管理、シフト作成、給与計算、会社マスタ設定 |
| **一般従業員 (User)** | 自分自身の勤怠打刻、申請、シフト希望、給与明細閲覧権限 | 打刻ダッシュボード、シフト希望提出、Web給与明細閲覧、入社手続き・産休申請 |

## 1.4 推奨動作環境とマルチデバイス対応
- **管理者画面**: PCブラウザ（Google Chrome, Microsoft Edge, Safari最新版推奨）
- **従業員画面**: スマートフォン（iOS Safari, Android Chrome）、タブレット、PC
- **A4印刷帳票**: ブラウザの印刷ダイアログ（`@media print`）より、倍率100%・「背景のグラフィックス」を有効にして印刷またはPDF保存してください。

## 1.5 ログイン・ポータルランチャー・パスワード再設定
- **通常ログイン (`/`)**: メールアドレスとパスワードを入力してログインします。
- **統合ポータルランチャー (`/portal`)**: ログイン後、権限に応じてアクセス可能なシステムカード（勤怠、労務、シフト、給与、会社設定）が一覧表示され、ワンクリックで遷移できます。
- **パスワード再設定 (`/reset-password`)**: パスワードを忘れた場合、登録メールアドレス宛に再設定リンクを即座に送信できます。
- **最高管理者ログイン (`/master-login`)**: SaaS運営者専用の隔離ログイン口です。

# 第2章：【入退社労務・電子申請ステーション】

## 2.1 従業員基本台帳（SSOT）の登録と一元管理
管理者画面（`/onboarding/admin`）では、在職中・入社手続き中・退職済みの全従業員をカードおよび一覧テーブルで俯瞰できます。

### 管理項目一覧
- **基本情報**: 氏名、フリガナ、生年月日、性別、現住所、電話番号、メールアドレス
- **雇用条件**: 雇用形態（正社員/契約社員/パート・アルバイト）、入社年月日、試用期間満了日、所属部署、役職
- **就業パターン**: 適用就業規則、始業時刻、終業時刻、休憩時間、所定労働日数、休日設定
- **給与・手当**: 給与形態（月給/時給/日給）、基本給/時給単価、役職手当、資格手当、住宅手当、家族手当、特別手当、固定残業代（時間・金額）
- **通勤条件**: 支給区分（月額定期/日額実費/なし）、通勤経路、月額通勤手当、非課税限度額自動判定
- **社会保険・税**: 健康保険加入有無、標準報酬月額、厚生年金加入有無、標準報酬月額、雇用保険加入有無、住民税月額（および6月〜翌5月の12ヶ月分特別徴収額）、扶養控除区分（甲欄/乙欄/丙欄）、扶養親族等の数、源泉控除対象配偶者
- **振込先口座**: 金融機関名、支店名、口座種別（普通/当座）、口座番号、口座名義人（カナ）

## 2.2 📱 スマホ入社手続きウィザード（新入社員向け）
管理者は、台帳一覧の「📱 スマホ入社URL」ボタンから、給与条件や雇用形態がプリセットされた専用入社手続きURL（QRコード・LINE送信文付き）を発行できます。
新入社員は手元のスマートフォンからログイン不要でアクセスし、以下のステップを約3分で完走できます。

1. **Step 1: 労働条件通知書 兼 雇用契約書の確認と電子同意**
   - 会社名、代表者名、社印影、就業場所、業務内容、賃金条件、退職に関する事項をスマホ実寸で精読。
   - 画面上で「同意して電子署名」にチェックを入れ、手書きまたは氏名タイピングにて法的有効性のある電子署名を完了。
2. **Step 2: 通勤交通費申請**
   - 自宅最寄駅、会社最寄駅、利用交通機関、1ヶ月定期代（または日額実費）を入力。
   - 定期券または交通系ICカードの写真をスマホカメラで撮影・アップロード（Canvas自動圧縮により通信量を90%削減）。
3. **Step 3: 給与振込口座登録**
   - 金融機関名、支店名、口座種別、口座番号、口座名義（カナ）を入力。
   - 通帳の表紙・見開き（またはキャッシュカード）を撮影・アップロード。
4. **Step 4: 令和8年分 扶養控除等申告書 ＆ 配偶者控除等申告書**
   - 配偶者の有無、扶養親族（16歳以上・特定扶養・老人扶養・16歳未満年少扶養）の氏名・続柄・生年月日・マイナンバーを入力。
   - 障害者控除、寡婦・ひとり親控除、勤労学生控除の該当有無をチェック。
5. **Step 5: マイナンバー ＆ 本人確認書類提出**
   - マイナンバーカード（表・裏）または通知カード＋運転免許証を撮影して安全に送信。

## 2.3 管理者側 書類審査ステーション
従業員から送信された書類は、管理画面の「提出書類審査ステーション」にリアルタイムで届きます。
- **提出エビデンス原本の確認**: アップロードされた写真原本をモーダルで拡大確認。
- **ワンクリック承認**: 「承認」ボタンを押すと、提出データが従業員台帳（SSOT）へ完全自動反映・マージされます。
- **差戻し（再提出依頼）**: 写真が不鮮明な場合や入力ミスがある場合、差戻し理由を明記してワンクリックで従業員へ再提出を要求できます。

## 2.4 📁 労務書面キャビネット（7大公式A4原本アーカイブ）
キャビネットを開くと、従業員ごとの法的提出書面が「日本の公的官公庁様式」に完全準拠した美しいレイアウトで自動生成・アーカイブされており、ワンクリックでA4印刷・PDF保存できます。

1. **労働条件通知書 兼 雇用契約書**: 労働基準法第15条準拠。会社印影・従業員電子署名・労働条件明示事項を完備。
2. **通勤交通費 申請・承認書**: 経路・定期代エビデンス写真を添付した社内決裁帳票原本。
3. **給与振込口座 登録届出書**: 金融機関情報と通帳見開き写真を一体化した振込委任状原本。
4. **令和8年分 給与所得者の扶養控除等（異動）申告書**: 国税庁最新様式を1ミリの狂いもなく再現。

6. **産前産後・育児休業 申請書 兼 住民税立替スケジュール表**: 休業期間と立替精算の法的合意文書。
7. **全社カスタム公的書類**: 企業独自の誓約書、身元保証書、機密保持誓約書（NDA）等。

## 2.5 👶 産前産後・育児休業 手続き＆書類管理ステーション
従業員の妊娠・出産・育児休業に伴う複雑な法令手続きを、完全に自動化する専門ステーションです。

### 主な機能
- **社員向けスマホ申請URL発行**: 社員へ専用URLを送信。社員は母子手帳の表紙（出産予定日記載面）の写真を添付し、予定日と希望を入力して送信。

  - 社員の精算希望（復職後の一括/分割天引き、または指定口座へ毎月振込）も自動記録。
- **公式A4印刷原本4種**:
  - 原本1: 産前産後休業・育児休業 取得申請書
  - 原本2: 住民税立替金に関する協定書・スケジュール表

# 第5章：【クラウド給与計算・WEB明細システム】

## 5.1 🖥️ 給与管理者ダッシュボード

### 勤怠データワンクリック完全自動連動
- 勤怠管理システムで締められた「実働時間」「時間外時間」「深夜時間」「休日時間」「欠勤日数」「遅刻早退時間」をボタン一つで完全自動取り込み。手動転記ミスを100%根絶します。

### 給与自動計算エンジン（労働基準法完全準拠）
1. **支給額の計算**:
   - 基本給（月給・時給・日給）
   - 固定残業代（設定時間を超えた分のみを追加残業手当として自動加算）
   - 時間外割増手当: `(基本給 ÷ 月平均所定労働時間) × 1.25 × 超過時間`
   - 深夜割増手当: `(単価) × 0.25 × 深夜時間`
   - 休日割増手当: `(単価) × 1.35 × 休日時間`
   - 各種手当（役職、資格、住宅、家族、特別手当）の自動合算
   - 通勤手当（非課税限度額150,000円/月を自動チェックし、超過分のみを課税対象に自動振分）
   - 欠勤控除・遅刻早退控除の自動計算
2. **社会保険料の自動計算**:
   - 従業員台帳に登録された「健康保険・厚生年金 標準報酬月額」を元に計算。
   - 都道府県別健康保険料率（47都道府県対応）、厚生年金保険料率（18.3%、折半9.15%）を自動適用。
   - **介護保険該当判定**: 従業員の生年月日から、当月において「40歳以上65歳未満」に該当するかどうかを日割りまで完全自動判定し、該当者のみ介護保険料を加算。
   - **雇用保険料**: 一般の事業（0.5%）、農林水産・清酒（0.6%）、建設の事業（0.6%）の法定労働者負担率を自動適用。
3. **税額の自動計算**:
   - **所得税**: 国税庁「給与所得の源泉徴収税額表（月額表）」に基づき、課税支給額から社会保険料等控除後の金額と扶養親族等の数から、甲欄・乙欄・丙欄の税額を完全自動算出。
   - **住民税**: 従業員ごとに登録された「月別特別徴収額（6月〜翌5月）」を参照し、当月の金額を自動控除。
4. **差引支給額（手取り額）の確定**:
   - `総支給額 - 総控除額（社会保険料合計 + 所得税 + 住民税 + その他控除） = 差引支給額` を1円単位で正確に確定。

### 総合振込データ（全銀協FBデータ）自動出力
- 全銀協標準フォーマット（テキスト形式）の総合振込依頼ファイルをワンクリック出力。
- インターネットバンキング（みずほ、三菱UFJ、三井住友、りそな、ゆうちょ、地方銀行、ネット銀行）へそのままアップロードして一括振込が完了します。

### Web給与明細の一括発行・公開制御
- 明細を「発行確定」すると、従業員のマイページへ即座に反映されます。
- 支給日前の事前チェック中は非公開にしておくことができます。

# 第8章：【SaaS統括管理・セキュリティ・サポート】

## 8.1 SaaSスーパー管理者ダッシュボード

- 全てのデータベースクエリにおいて、認証ユーザーの `tenant_id` で物理的に厳格フィルタリング。

# 第9章：【業務運用フロー・ベストプラクティス】

## 9.1 新入社員の採用から社会保険加入までの流れ
1. **URL発行**: 管理者が「📱 スマホ入社URL発行」から雇用条件を選択してURLを発行し、内定者へLINEまたはメールで送付。
2. **内定者の入力**: 内定者が手元のスマホで契約書に電子署名し、通勤・口座・扶養情報・本人確認書類を送信。
3. **管理者の審査**: 管理画面に通知が届き、提出内容と写真を点検して「承認」ボタンをクリック。
4. **自動台帳登録**: 従業員台帳（SSOT）へ自動マージされ、打刻用アカウントが即座に有効化。
5. **行政帳票印刷**: 「健康保険・厚生年金被保険者資格取得届」および「雇用保険被保険者資格取得届」が自動作成されるため、A4印刷してハローワーク・年金事務所へ提出。

## 9.2 日々の勤怠打刻・残業管理の流れ
1. **打刻**: 従業員が現場・店舗・オフィスでスマホまたはPCからワンタップ打刻（GPS位置情報を自動取得）。
2. **リアルタイム確認**: 管理者がダッシュボードで出勤状況や36協定残業時間を随時チェック。
3. **修正申請**: 打刻漏れや有給申請があった場合、管理者が承認ボタンを押して即座に反映。

## 9.3 毎月の給与計算・振込・明細公開の流れ
1. **勤怠締め**: 締め日到来後、管理者が「勤怠月次締め」を実行して労働時間数を確定。
2. **給与自動計算**: 給与管理画面を開くと、勤怠データ・基本給・手当・社会保険料率・所得税表から全自動で給与明細が算出・一覧表示。
3. **全銀FBデータ出力**: 振込ボタンからFBデータをダウンロードし、ネット銀行へアップロードして振込完了。
4. **Web明細一括公開**: 「明細発行確定」ボタンを押すと、全従業員のスマホへ最新の給与明細が配信。

## 9.4 産休・育休の申請受付から住民税立替・原本印刷の流れ
1. **申請依頼**: 管理者が「👶 産休・育休手続き」から専用URLを発行して社員へ送付。
2. **社員の申請**: 社員が母子手帳の写真を添付し、出産予定日を入力して電子署名送信。
3. **全自動連動計算**: モーダルを開くと、産前・産後・育児休業期間、復職日、住民税立替スケジュールが完全自動計算・反映。
4. **行政原本印刷**: A4原本（取得申請書、協定書、母子手帳台紙、チェックリスト）を印刷して公的機関へ提出。

## 9.5 退職手続きから離職票作成までの流れ
1. **退職確定**: 管理者が台帳で「退職」ボタンを押し、退職日と事由を選択して確定。
2. **自動帳票出力**: ハローワーク提出用の「雇用保険被保険者資格喪失届」および「離職証明書（離職票）」をA4印刷して提出。

# 第10章：よくある質問（FAQ）＆トラブルシューティング

### Q1. 従業員のスマートフォンでGPS位置情報が取得できないと言われます
- **回答**: スマートフォン端末またはブラウザ（SafariやChrome）の「位置情報サービス」がオフになっているか、ブラウザからの位置情報アクセスが「不許可」になっている可能性があります。
- **対処法**: iPhoneの場合は「設定 ➔ プライバシーとセキュリティ ➔ 位置情報サービス ➔ Safari」、Androidの場合は「設定 ➔ アプリ ➔ Chrome ➔ 権限 ➔ 位置情報」を「許可（このAppの使用中のみ許可）」に設定してください。

### Q2. 産休・育休モーダルを開いても出産予定日や立替表が空欄のままです
- **回答**: 本最新バージョンにて「4重フォールバック復元エンジン」が配備されました。社員が一度でもスマホ申請を完了していれば、モーダルを開いた瞬間に提出書類原本（`employee_document_submissions`）から自動取得され、予定日・期間・立替表が100%自動反映されます。
- **対処法**: ブラウザのキャッシュが残っている可能性があるため、**Ctrl + F5（強制リロード）**を実行した上で再度お試しください。

### Q3. 給与計算で介護保険料が引かれている人と引かれていない人がいます
- **回答**: 介護保険法第9条に基づき、介護保険第2号被保険者は「40歳に達した日（40歳の誕生日の前日）の属する月」から「65歳に達する日の前日の属する月の前月」まで徴収義務があります。システムが生年月日からこれを日割りまで完全自動判定しているため、正常な動作です。

### Q4. A4原本印刷で右端が見切れたり、2ページ目に1行だけはみ出ます
- **回答**: ブラウザの印刷ダイアログの余白設定が原因です。
- **対処法**: 印刷画面の「詳細設定」を開き、
  - **用紙サイズ**: A4
  - **余白**: 「なし」または「最小」
  - **倍率**: 「既定（100%）」または「用紙に合わせる」
  - **オプション**: 「背景のグラフィック」にチェックを入れてください。

### Q5. 提出された通帳や母子手帳の写真の容量が大きすぎて送信エラーになりませんか？
- **回答**: 本システムには「ブラウザ側Canvas自動画像圧縮エンジン（`imageCompressor.ts`）」が組み込まれています。高画質なスマホカメラ写真（5MB〜10MB）であっても、送信前に端末内で自動的に長辺1600px・WebP/JPEGへ軽量化（200KB〜400KB程度）してからアップロードされるため、通信制限中や電波の弱い環境でもサクサク送信できます。
