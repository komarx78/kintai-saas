# 🛡️ 夜間自動巡回・自律防衛要塞システム（Nightly Patrol Bot）

本システムは、人間が就寝している夜間（または不在時）に、Pythonとヘッドレスブラウザ（Playwright）を用いて**システムの全画面・全機能を完全無人で自動巡回・限界耐久テストし、翌朝に「要塞健康診断カルテ」を出力する自動化兵器**です。

---

## 🌟 主な機能と検証範囲

1. **🖥️ 画面自動操作 ＆ クラッシュ検知（Playwright）**:
   - 画面を開き、主要なボタン操作、フォーム入力、モーダル展開を自動シミュレート。
   - 画面の真っ白（Whiteout）や、未補足のJavaScript例外、ブラウザコンソールエラーを逃さず検知。
2. **🏢 業種別テンプレート一括作成 ＆ 実DB永続化監査**:
   - 会社設定画面からテンプレート一括作成を実行。
   - 画面上の反映確認に加え、裏から Supabase REST API を直接クエリして **PostgreSQL の UUID 型制約違反やデータ欠損がないか（実DB永続化）** を物理照合。
3. **💥 イレギュラー・限界値ファジング攻撃**:
   - 40歳到達月の介護保険判定境界（39歳・40歳・65歳）。
   - 特殊文字（髙、﨑、絵文字）、100文字超の長文、XSS/SQLインジェクション風の記号に対するサニタイズ耐性。
   - 扶養親族数の極端値（0人〜15人超）における税額表インデックス保護。
4. **📋 毎朝の健康診断カルテ自動生成**:
   - 巡回完了後、`reports/latest_patrol_report.md` に結果を自動出力。
   - 朝起きた時にファイルを開くだけで、システムが健全か（あるいはどこに警告があるか）が1秒で分かります。

---

## 🚀 手動での実行方法

### 方法 A: ワンクリックで実行
`nightly_patrol\run_patrol.bat` をダブルクリックするだけです。

### 方法 B: コマンドラインから実行
```bash
python nightly_patrol\run_patrol.py
```

※ 画面を見ながら動作確認したい場合は、環境変数 `PATROL_HEADLESS=false` を設定して実行してください。
